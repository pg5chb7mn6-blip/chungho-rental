# 청호렌탈 일일 발행

하루 한 편, 같은 주제를 **네이버 블로그와 자사 사이트에 각각 다른 문장으로** 올린다.
네이버 블로그만으로는 구글·다음에 자산이 안 쌓이고, 사이트만으로는 네이버 통합검색에 안 걸린다.

## 시작 전 확인 (매번, 30초)

```bash
python3 tools/apply_config.py --check
```

`{{네이버_서치어드바이저_인증코드}}` 나 `{{구글_서치콘솔_인증코드}}` 가 남아 있으면 **글을 아무리 써도 색인되지 않는다.**
이 경우 원고 작업보다 이걸 먼저 사용자에게 알린다. `ops/체크리스트-초기세팅.md` 를 안내한다.

## 진행 순서

### 1단계 — 오늘의 주제 (keyword-scout)
`keyword-scout` 에이전트를 호출한다. `ops/키워드-맵.md` 와 `ops/posts/` 의 기존 주제를 읽고 오늘의 키워드와 취재 노트를 만들어 온다.

사용자가 주제를 직접 지정했다면 이 단계를 건너뛰되, 중복 여부는 확인한다.

### 2단계 — 원고 두 벌 (blog-writer)
1단계 취재 노트를 **그대로 붙여** `blog-writer` 에이전트에 넘긴다. 산출물:
- `ops/posts/naver/YYYY-MM-DD-<slug>.md` — 네이버 블로그 붙여넣기용 (이미지 촬영 지시, 해시태그 포함)
- `ops/posts/YYYY-MM-DD-<slug>.md` — 사이트용 마크다운 원고

### 3단계 — 전환 동선 (lead-closer)
`lead-closer` 에이전트를 호출해 이 글의 `preset` 딥링크와 CTA 문구를 정한다. 사이트 원고 머리말에 반영한다.

### 4단계 — 검수 (seo-auditor)
`seo-auditor` 에이전트를 호출한다. **보류 판정이면 2단계로 돌아간다.** 통과할 때까지 반복한다.

### 5단계 — 빌드
```bash
python3 tools/build_blog.py
python3 tools/apply_config.py
```
`blog/<slug>/index.html` 생성, `blog/index.html`·`sitemap.xml`·`rss.xml`·메인 최신글 목록이 함께 갱신된다.

### 6단계 — 커밋·푸시
```bash
git add -A
git commit -m "블로그: <제목>"
git push -u origin claude/cheonho-rental-seo-blog-3faixj
```

### 7단계 — 사람이 직접 해야 하는 일 출력
자동화할 수 없는 부분이다. 아래를 **체크박스 형태로** 사용자에게 출력한다.

```
오늘 직접 하실 것

[ ] 1. 네이버 블로그에 붙여넣기
       원고: ops/posts/naver/<파일>.md
       - 이미지 지시대로 직접 찍은 사진 5장 이상 삽입 (스톡 이미지는 효과 없음)
       - 표는 스마트에디터 표 기능으로 다시 그리기 (이미지로 넣지 말 것)
       - 해시태그 10개 입력
       - 발행 시각: 평일 오전 8~9시 또는 오후 8~10시

[ ] 2. 네이버 서치어드바이저 → 요청 → 웹페이지 수집
       https://pg5chb7mn6-blip.github.io/chungho-rental/blog/<slug>/
       (하루 할당량이 있으니 새 글부터)

[ ] 3. 구글 서치콘솔 → URL 검사 → 색인 생성 요청
       같은 URL

[ ] 4. 네이버 블로그 글 하단에 사이트 링크 1개 확인 (도배 금지)
```

## 규칙

- **하루 한 편.** 몰아서 5편 쓰고 나흘 쉬는 것보다, 매일 한 편이 네이버 지수에 훨씬 유리하다.
- **네이버 원고와 사이트 원고의 문장을 복사하지 않는다.** 4단계 검수에서 겹침 25% 초과면 무조건 보류.
- **없는 숫자를 만들지 않는다.** 렌탈료·위약금·필터 주기는 "조건에 따라 다릅니다"로 처리한다.
- 발행 결과는 `ops/발행기록.md` 에 한 줄 남긴다: 날짜, 주력 키워드, 사이트 slug, 네이버 발행 여부.
