# 제품 이미지 적용 — 인수인계 (2026-11-10)

## 결정된 것
- 메인 화면은 **시안 B(애플 스타일 제품 진열)** 로 간다.
- 일러스트(누끼 대용)는 임시이며, **청호나이스 공식 홈페이지의 제품 이미지**로 교체한다.
- 이미지 사용은 청호나이스 직원인 요청자가 허가를 받았다고 밝혔다. 허가 근거(담당자·일자·범위)를 아래 "출처·허가 기록"에 남겨 둘 것.
- 기존과 동일하게 **제품 이미지는 제품 코드(`data.js` 의 `p[0]`, 예: `Z10562`)로 따라온다.**

## 이미 준비된 것 (`design/b/index.html`)
이미지 로더가 코드별로 아래 순서로 찾고, 없으면 일러스트를 그대로 둔다.

1. `images.js` 의 `window.PRODUCT_IMAGES[코드]` (관리자 도구 `admin.html` 로 넣은 사진)
2. `assets/products/<코드>.webp` → `.png` → `.jpg`
3. 일러스트(폴백)

| 자리 | 코드 | 모델 |
| --- | --- | --- |
| 정수기 대형 타일 | `Z10562` | 슈퍼 아이스트리 |
| 공기청정기 타일 | `Z24252` | A600S |
| 매트리스 타일 | `M20001` | 로얄스위트 프라임 |
| 비데 타일 | `Z21069` | B600 PLUS |
| 사무실·매장 타일 | `Z10568` | OMNi Plus |
| 라인업 레일 8칸 | 위 코드 + `Z24266` `M47001` `Z21038` | 휘바람 숨소리3, 듀얼 드림 온열, B350 |

- 흰 배경 사진이면 밝은 타일에서는 `multiply` 로 배경을 녹이고, 어두운 타일은 자동으로 밝은 타일로 바뀐다.
- **투명 배경(누끼 PNG/WebP)이면 가장 애플답게 나온다.** 공식 이미지가 흰 배경뿐이면 배경 제거를 거치는 편이 낫다.

## 다음 세션에서 할 일
**환경 `chungho-rental` 로 새 세션을 시작해야 한다.** 이 환경은 `www.chungho.co.kr` 접속이 허용돼 있다. (기존 세션은 실행 중에 환경을 옮길 수 없다.)

1. `www.chungho.co.kr` 에서 위 모델의 제품 이미지를 찾는다. 이미지가 다른 호스트(CDN)에 있으면 그 호스트를 추가로 허용해야 한다.
2. `assets/products/<코드>.webp` 로 저장한다. 긴 변 1600px 이하, 용량은 장당 300KB 안팎.
3. 흰 배경이면 배경 제거를 시도하고, 품질이 낮으면 흰 배경 그대로 쓴다.
4. 계산기 제품 카드에도 따라오도록 `images.js` 를 같은 코드로 채운다(기존 `imgTag(p[0])` 는 그대로).
5. 시안 B 의 히어로를 `index.html` 에 이식하고, 매트리스 정적 안내 페이지를 추가한다.
