# 네이버 블로그 운영 규칙

네이버는 구글과 다른 기준으로 글을 고릅니다. 구글 방식으로 쓰면 네이버에서는 안 걸립니다.

---

## 네이버가 보는 것

네이버 검색은 크게 두 가지를 봅니다.

**C-Rank — 블로그(출처) 자체의 신뢰도**
- 이 블로그가 **한 주제를 꾸준히** 다뤄왔는가
- 발행이 **끊기지 않는가**
- 이 블로그 글이 실제로 **소비되는가** (체류시간, 스크롤, 이웃)

**D.I.A. — 글 하나하나의 실질**
- 검색 의도에 **직접 답하는가**
- **직접 경험한 내용**이 들어 있는가
- 복붙·기계 번역·유사문서가 아닌가

여기서 나오는 결론은 단순합니다.

> **한 주제로, 매일, 직접 찍은 사진과 함께, 남과 다른 문장으로 쓴다.**

---

## 절대 규칙 (어기면 노출이 죽습니다)

### 1. 사이트 글과 문장을 복사하지 않는다
네이버는 유사문서를 강하게 걸러냅니다. 같은 문장을 사이트와 블로그에 올리면 **둘 다** 노출이 떨어집니다.
같은 사실을 다루되 예시·순서·문장을 새로 씁니다. 발행 전 반드시 확인:

```bash
python3 tools/similarity_check.py ops/posts/naver/<파일>.md ops/posts/<파일>.md
```

겹침 25% 초과면 다시 씁니다.

### 2. 스톡 이미지를 쓰지 않는다
네이버는 어디서나 볼 수 있는 이미지를 구분합니다. **직접 찍은 사진**이 있는 글과 없는 글의 차이가 큽니다.
설치 현장, 제품 실물, 견적서 화면(개인정보 가린 상태), 상담 메모 — 무엇이든 직접 찍은 게 낫습니다.
글 하나에 **최소 5장**.

### 3. 링크를 도배하지 않는다
글 하나에 외부 링크 **1개**. 마지막에 자연스럽게. 링크가 많으면 홍보성으로 분류됩니다.

### 4. 키워드를 억지로 반복하지 않는다
주력 키워드는 본문에 **5~7회**. 그 이상은 어뷰징으로 봅니다. 문장 안에 자연스럽게 녹여야 합니다.

### 5. 발행을 끊지 않는다
C-Rank는 **꾸준함**을 봅니다. 5편 몰아 쓰고 나흘 쉬는 것보다 매일 한 편이 훨씬 유리합니다.
주 5편이 어렵다면 주 3편이라도 **같은 요일에 규칙적으로** 하십시오.

---

## 글 하나의 표준 형태

| 항목 | 기준 |
| --- | --- |
| 제목 | 25~32자. 주력 키워드를 앞쪽 1/3 안에 |
| 첫 문단 | 주력 키워드 1회 필수. 결론을 먼저 |
| 분량 | 공백 포함 **1,700자 이상** |
| 이미지 | 5장 이상, 직접 촬영. 소제목마다 1장 |
| 표 | 1개 이상. 스마트에디터 표 기능으로 (이미지로 넣지 말 것) |
| 소제목 | 4~6개 |
| 해시태그 | 10개. 주력 + 롱테일 + 지역 |
| 외부 링크 | 1개 (사이트 견적 계산기) |
| 공식 판매점 표기 | 1회 |

## 발행 시각

- **평일 오전 8~9시** — 출근길 검색
- **평일 오후 8~10시** — 퇴근 후 검색

렌탈은 저녁에 알아보는 사람이 많습니다. 주말 낮은 반응이 낮습니다.

---

## 이렇게 쓰면 안 됩니다

- "정수기렌탈 최저가 문의주세요" 같은 홍보 일변도 글 → 검색에서 걸러집니다
- 제품 사양만 나열한 글 → 본사 페이지가 이깁니다. 이길 수 없습니다
- "정수기렌탈 정수기렌탈 정수기렌탈" 키워드 나열 → 어뷰징
- 다른 블로그 글을 요약해서 옮긴 글 → 유사문서
- 서로이웃 품앗이로 조회수 올리기 → 체류시간이 짧아 오히려 손해

---

## 이렇게 쓰면 됩니다

**상담하면서 실제로 있었던 일**을 씁니다.

- "지난주에 20명 사무실 상담을 갔는데, 정수기 한 대로 버티려다 점심시간마다 줄이 선다고 하셨습니다."
- "이사 앞두고 위약금 때문에 연락 주신 분이 계셨는데, 계산해보니 이전설치가 훨씬 쌌습니다."

이런 도입은 네 가지를 동시에 해결합니다.
1. 직접 경험 → D.I.A.가 좋아합니다
2. 검색 의도와 정확히 일치 → 그 상황을 검색한 사람이 끝까지 읽습니다
3. 체류시간이 늘어납니다
4. 신뢰가 생겨 상담으로 이어집니다

**단, 실제로 있었던 일만 쓰십시오.** 지어낸 사례는 상담 전화에서 앞뒤가 안 맞게 되고, 그게 계약을 깹니다.

## 매주 확인할 것

네이버 블로그 관리 → 통계에서:

| 지표 | 볼 것 |
| --- | --- |
| 유입 경로 | **검색 유입 비율**. 이게 늘어야 진짜입니다. 이웃 유입만 늘면 의미 없습니다 |
| 검색 유입 키워드 | 어떤 말로 들어왔는가 → 그 키워드로 후속 글을 씁니다 |
| 평균 사용 시간 | 1분 미만이면 글이 검색 의도에 안 맞는 것입니다 |
| 조회수 상위 글 | 이 주제를 더 깊게 파고, 사이트에도 같은 주제 글을 둡니다 |

**검색 유입 비율**이 유일하게 중요한 숫자입니다. 나머지는 참고용입니다.
