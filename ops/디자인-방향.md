# 메인 화면 디자인 방향 (2026-11-10)

시안 3종은 `design/` 에 있습니다 (`/design/a/`, `/design/b/`, `/design/c/`). 검색 노출 제외(noindex) 상태이며, 버튼은 실제 견적 계산기로 조건이 채워진 채 연결됩니다.

## 공통 원칙 — "촌스러움"을 피하기 위해 지킨 것

| 원칙 | 적용 |
| --- | --- |
| 색은 적게 | 따뜻한 중립색 바탕 + 포인트 1색. 그라데이션·그림자로 장식하지 않음 |
| 타이포가 디자인의 절반 | 헤드라인 52~84px, 자간 -0.05em, 본문 15~17px. 위계는 크기·굵기·회색 3단계로만 |
| 여백은 비워 두기 | 섹션 간격 80~110px. 카드 안 여백도 넉넉히 |
| 아이콘·이모지 장식 금지 | 의미 있는 곳(화살표, 핫스팟)에만 선 아이콘 |
| 움직임은 한 번만, 짧게 | 등장 시 페이드업, 호버 시 살짝 떠오름. `prefers-reduced-motion` 존중 |
| 한 화면에 행동 하나 | 첫 화면의 질문은 "어떤 공간이 필요하세요?" 하나 |
| 가격 숫자 금지 | 확정되지 않은 월 렌탈료를 디자인에 박지 않음. "월 렌탈료 보기"로 계산기에 연결 |

## 3종 비교

| | A 집 단면 | B 제품 진열 | C 에디토리얼 |
| --- | --- | --- | --- |
| 참고한 패턴 | 인테리어 쇼룸, 핫스팟 제품 태그 | Apple 제품군 페이지(큰 타일, 라인업 레일) | 매거진·스튜디오 사이트(타이포 인덱스 + 호버 스테이지) |
| 분위기 | 따뜻하고 친근, 가정 상담에 어울림 | 선명하고 신뢰감, 제품 중심 | 차분하고 고급스러움 |
| 첫 화면 행동 | 방 4개 중 하나 클릭 | 스크롤하며 제품 훑기 | 목록에 올려 보고 클릭 |
| 사진 의존도 | 낮음(일러스트로도 완성) | **높음**(실제 제품 사진이 들어가야 완성) | 중간 |
| 모바일 | 가로 스와이프 카드 | 세로 타일 | 목록만 남김(스테이지 숨김) |
| 약점 | 일러스트 퀄리티가 곧 사이트 퀄리티 | 사진이 없으면 심심함 | 연령대 높은 고객에겐 낯설 수 있음 |

## 추천

**A를 기본으로, B의 "대표 라인업 레일"을 아래에 붙이는 조합.**
- 렌탈 고객은 "어떤 제품이 있나"보다 "우리 집에 뭐가 맞나"를 먼저 묻기 때문에 공간 중심 진입(A)이 전환 동선에 맞습니다.
- 실제 제품 사진이 확보되면 B의 라인업 레일로 신뢰감을 보강합니다.

## 정직하게 밝혀 둘 한계

- **일러스트는 임시 이미지입니다.** 제품 사진·시공 사례 사진이 확보되면 각 시안 파일 안의 인라인 SVG를 `<img>` 로 교체하면 됩니다. 사진 한 장이 일러스트 열 장보다 신뢰도가 높습니다.
- 레퍼런스(Apple, Samsung Bespoke, Muji, Aesop 등)는 실시간으로 열어 비교하지 못했고, 알려진 레이아웃 패턴을 바탕으로 직접 구성했습니다. 디자인을 베낀 것이 아니라 패턴만 참고했습니다.
- 시안은 메인 첫 화면(히어로)만 다룹니다. 기존 견적 계산기·프로모션·문의 폼은 그대로 두었습니다.

## 채택 후 작업

1. 선택한 시안의 히어로를 `index.html` 의 `<header class="hero">` 자리에 이식 (견적 계산기 로직은 유지)
2. 매트리스 정적 안내 페이지 신설 (현재 `/mattress/` 가 없어 검색 유입 경로가 비어 있음)
3. 실제 제품 사진 교체, 사업자 정보 플레이스홀더 치환 (`ops/체크리스트-초기세팅.md`)
