# 청호렌탈 SEO 및 블로그 운영

이 폴더는 **매일 블로그를 발행해서 정수기 렌탈 상담까지 이어지게 만드는 운영 체계**입니다.

---

## 지금 당장 해야 할 것

```bash
python3 tools/apply_config.py --check
```

`{{네이버_서치어드바이저_인증코드}}` 같은 항목이 남아 있으면, **글을 아무리 써도 검색에 안 잡힙니다.**
→ `ops/체크리스트-초기세팅.md` 를 먼저 끝내십시오. 여기가 하루 2~4명의 가장 큰 원인입니다.

원인 분석 전체는 `ops/진단-유입부진-원인.md` 에 있습니다.

---

## 매일 하는 일

```
/daily-blog
```

한 번 실행하면 아래가 순서대로 돌아갑니다.

| 단계 | 담당 | 하는 일 |
| --- | --- | --- |
| 1 | `keyword-scout` | 오늘 이길 수 있는 키워드를 찾아 취재 노트를 만든다 |
| 2 | `blog-writer` | 네이버용·사이트용 원고 **두 벌**을 서로 다른 문장으로 쓴다 |
| 3 | `lead-closer` | 이 글에서 견적·상담으로 넘어가는 동선을 붙인다 |
| 4 | `seo-auditor` | 검색엔진 요건·법적 표현·유사문서를 검수하고 통과/보류 판정 |
| 5~6 | (자동) | 빌드 → 커밋 → 푸시 |
| 7 | 사람 | 네이버 블로그 붙여넣기 + 색인 요청 (자동화 불가) |

**7단계는 사람이 해야 합니다.** 네이버 블로그에 직접 찍은 사진을 넣는 일과 색인 요청은 자동화할 수 없고, 그게 네이버 노출의 핵심입니다.

---

## 팀 구성

4명입니다. 더 늘리지 않았습니다 — 사람이 늘면 손발이 안 맞고, 지금 병목은 사람 수가 아닙니다.

| 에이전트 | 역할 | 왜 필요한가 |
| --- | --- | --- |
| `keyword-scout` | 자료수집·키워드 | 이길 수 있는 키워드를 고르는 게 글의 질보다 중요하다 |
| `blog-writer` | 원고 작성 | 네이버용·사이트용을 다르게 쓰는 게 핵심 기술이다 |
| `seo-auditor` | 검수 | 법적 표현 하나로 사업이 흔들릴 수 있고, 유사문서 하나로 노출이 죽는다 |
| `lead-closer` | 전환·영업 | 유입 자체는 목표가 아니다. 상담이 목표다 |

만들지 않은 것: 디자인·이미지 에이전트(네이버는 **직접 찍은** 사진을 원한다 — AI가 대신할 수 없음), 광고 운영 에이전트(지금 단계에서는 검색이 우선), 별도 리서치 에이전트(`keyword-scout` 가 겸함).

## 도구

| 명령 | 하는 일 |
| --- | --- |
| `python3 tools/apply_config.py` | 사업자 정보·인증코드 일괄 치환, GA4/네이버 애널리틱스 삽입 |
| `python3 tools/apply_config.py --check` | 파일은 안 건드리고 남은 항목만 확인 |
| `python3 tools/build_blog.py` | `ops/posts/*.md` → `blog/` 정적 HTML + sitemap + rss + 메인 최신글 |
| `python3 tools/similarity_check.py A.md B.md` | 두 원고의 문장 겹침 검사 (25% 초과면 다시 쓰기) |

## 원고 쓰는 법

`ops/posts/_TEMPLATE.md` 를 복사해서 시작합니다. 지원하는 문법은 그 파일에 다 있습니다.

머리말에서 하나라도 빠지면 빌드가 실패합니다: `title` `description` `slug` `date` `category` .
`category` 는 `비용` `제품` `계약` `관리` `사무실` `지역` 중 하나입니다.

---

## 기대치

- **1~2주**: 변화 없음 (네이버 색인 대기)
- **3~4주**: 구글에서 롱테일 유입 시작, 하루 10~20명
- **2~3개월**: 네이버 색인 붙음, 하루 30~80명
- **4~6개월**: 하루 100명 이상, 주 단위 상담 문의

한 달 만에 하루 100명이 되는 방법은 광고뿐입니다. 검색은 누적이고, 대신 한 번 쌓이면 비용이 안 듭니다.
