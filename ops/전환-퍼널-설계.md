# 전환 퍼널 설계 — 유입을 계약까지

유입이 늘어도 상담이 안 들어오면 의미가 없습니다. 이 문서는 **들어온 사람을 어디서 놓치고 있는지**를 관리합니다.

---

## 전체 동선

```
네이버 블로그 ─┐
              ├→ 사이트 블로그 글 → 견적 계산기(#quote) → 상담 신청 폼 ─┐
구글/다음 검색 ─┘                          └→ 카카오 오픈채팅 ──────────┤
                                                                      ↓
                                                        통화 → 조건 확정 → 설치일 → 계약
```

---

## 단계별로 어디서 새는가

| 구간 | 빠져나가는 이유 | 손댈 것 | 현재 상태 |
| --- | --- | --- | --- |
| 검색 → 글 | 애초에 검색에 안 뜸 | 색인 등록, 롱테일 글 | ❌ 소유확인 미완료 |
| 글 → 계산기 | 답만 얻고 나감 | 글마다 조건이 채워진 `preset` 딥링크 | ✅ 적용됨 |
| 계산기 → 폼 | 금액 확인이 목적이었음 | "이 조건이 맞는지 확인" 이라는 다음 이유 | △ 개선 여지 |
| 폼 → 통화 | 언제 연락 올지 몰라 불안 | 완료 화면에 연락 시점 명시 | △ 확인 필요 |
| 통화 → 계약 | 다른 곳과 비교 중 | 비교하기 쉬운 형태로 먼저 정보 제공 | — |

---

## 글 → 계산기: 프리셋 딥링크

메인 페이지 견적 계산기는 URL 쿼리스트링으로 조건을 미리 채울 수 있습니다.

```
?c=<계약구분>&s=<규정>&m=<관리방식>&o=<개월>&g=<제품군>#quote
```

| 파라미터 | 뜻 | 값 예시 |
| --- | --- | --- |
| `c` | 계약 구분 | 개인 |
| `s` | 규정 | S |
| `m` | 관리 방식 | 방문관리 |
| `o` | 의무사용기간(개월) | 36 / 60 |
| `g` | 제품군 | 얼음정수기 / 냉온정수기 / 공기청정기 / 비데군 / 연수기군 / 제습기 |

한글 값은 URL 인코딩이 필요합니다.

```bash
python3 -c "import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))" 얼음정수기
```

글 머리말의 `preset` 에 넣으면 그 글의 CTA 버튼이 조건이 채워진 상태로 계산기를 엽니다.
**"계산기 열기"보다 "이미 반쯤 채워진 계산기"의 전환율이 훨씬 높습니다.**

글 주제별 권장 프리셋:

| 글 주제 | 프리셋 방향 |
| --- | --- |
| 얼음정수기 관련 | `g=얼음정수기`, `o=60` |
| 원룸·1인가구 | `g=냉온정수기`, `m=자가관리`, `o=36` |
| 사무실·매장 | `g=냉온정수기`, `o=60` |
| 위약금·해지 | `o=36` (짧은 약정을 먼저 보여주는 편이 맥락에 맞음) |
| 렌탈료 비교 | 프리셋 없이 (직접 조건을 고르게) |

## 문의 응대 스크립트

### 첫 답장 — 30분 안에

렌탈 문의는 여러 곳에 동시에 넣습니다. **먼저 답한 곳이 이깁니다.** 늦게 답하면 내용이 아무리 좋아도 이미 다른 곳과 얘기가 진행됩니다.

### 가격만 묻는 문의

❌ "정수기는 월 3만원부터입니다"
→ 조건 없이 숫자만 던지면 비교당하기만 하고 대화가 끝납니다.

✅ 이렇게:
> 조건에 따라 금액이 꽤 달라져서요. 세 가지만 알려주시면 정확하게 계산해서 보내드리겠습니다.
> 1) 몇 분이 쓰시나요 (가정이면 가족 수, 사무실이면 상주 인원)
> 2) 설치 위치가 어디인가요 (주방 싱크대 옆 / 탕비실 등)
> 3) 몇 년 정도 쓰실 계획인가요
>
> 참고로 렌탈은 의무사용기간이 있고, 그 안에 해지하면 위약금이 발생합니다. 그래서 3번이 금액에 가장 크게 영향을 줍니다.

**위약금을 먼저 말하는 게 핵심입니다.** 숨기면 계약 후 클레임이 되고, 먼저 말하면 신뢰가 됩니다.

### "다른 곳이랑 비교 중이에요"

막지 말고 **비교하기 쉽게 만들어줍니다.** 조건을 정확히 적은 쪽이 대부분 이깁니다.

> 비교해보시는 게 맞습니다. 비교하실 때 이 네 가지를 같은 조건으로 놓고 보셔야 의미가 있습니다.
> - 부가세 포함 월 렌탈료
> - 의무사용기간과 그 기간 총액
> - 설치비·등록비가 따로 있는지
> - 중도해지 위약금 산정 기준
>
> 저희 조건은 아래와 같습니다. (숫자로 정리해서 제시)

### 계약을 미루는 문의

> 계약서 받아서 보시고 결정하셔도 됩니다. 궁금한 조항 있으면 언제든 물어보세요.

당일 계약을 압박하지 않습니다. **압박하지 않는 쪽이 성사율이 높습니다.** 렌탈은 몇 년짜리 계약이라 사람들이 경계합니다.

---

## 하지 말아야 할 것

- 상담 폼에서 이름·연락처·설치지역 **이상의 개인정보를 요구하지 않습니다.**
- 광고 수신 동의를 **필수로 만들지 않습니다.** 거부해도 상담에 불이익이 없어야 합니다.
- **없는 프로모션을 만들지 않습니다.** "오늘까지", "마감 임박" 같은 압박 문구를 쓰지 않습니다.
- 확정되지 않은 금액을 확정된 것처럼 말하지 않습니다.

- 유입 — 구글 서치콘솔 + 네이버 서치어드바이저 + 네이버 애널리틱스
- 계산기 도달·폼 제출 — GA4

## 참고: 유입이 늘기 전에 미리 준비할 것

유입이 늘어난 다음에 준비하면 늦습니다. 지금 해두십시오.

- [ ] 상담 폼 제출 알림을 **휴대폰으로 즉시** 받도록 설정 (Google Apps Script → 이메일/푸시)
- [ ] 카카오 오픈채팅 알림 켜두기
- [ ] 자주 쓰는 답변 3개를 메모 앱에 저장 (가격 문의 / 비교 중 / 설치 가능 여부)
- [ ] 견적서 양식 준비 — 위 네 가지 항목이 다 적힌 형태
