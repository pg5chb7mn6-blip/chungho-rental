# 초기 세팅 체크리스트 — 오늘 안에 끝내야 할 것

이 문서의 0·1·2번을 안 하면 블로그를 매일 써도 유입이 늘지 않습니다. 순서대로 하십시오.

---

## 0. 사이트 주소 이전 ❗네이버 등록의 선행 조건

**네이버 서치어드바이저는 사이트를 호스트(도메인) 단위로만 등록받습니다.**

```
❌ https://pg5chb7mn6-blip.github.io/chungho-rental/   → "URL을 호스트 단위로 입력해주세요"
✅ https://내도메인.co.kr/
```

지금 사이트는 GitHub 프로젝트 페이지라 `/chungho-rental/` 하위 경로에 있습니다.
호스트 루트(`pg5chb7mn6-blip.github.io/`)는 담당 저장소가 없어 404이므로, 그 주소로 등록해도
**소유확인 파일을 놓을 자리가 없어 확인이 실패합니다.**

→ 주소를 호스트 루트로 옮기지 않으면 네이버 등록 자체가 불가능합니다.

### 두 가지 방법

| | A. 커스텀 도메인 **(권장)** | B. 저장소 이름 변경 |
| --- | --- | --- |
| 결과 주소 | `https://내상호.co.kr/` | `https://pg5chb7mn6-blip.github.io/` |
| 비용 | 연 2만원 안팎 | 무료 |
| 걸리는 시간 | DNS 전파 최대 24시간 | 즉시 |
| 네이버 등록 | 가능 | 가능 |
| 신뢰도 | 상담·계약 유도 사이트에 적합 | 무작위 문자열이라 개인 테스트 페이지로 보임 |
| 나중에 또 옮겨야 하나 | 아니오 | **예 — 결국 도메인을 사면 다시 옮겨야 함** |

**B로 갔다가 나중에 A로 가면 색인을 두 번 초기화하게 됩니다.** 도메인을 살 계획이 조금이라도 있다면
처음부터 A로 가십시오. 지금은 글이 4편뿐이라 이전 비용이 가장 쌉니다.

> 도메인은 **본인 상호를 포함한 이름**으로 사십시오. `청호나이스`만 단독으로 쓴 도메인은
> 본사 공식몰로 오인될 소지가 있어 상표·부정경쟁방지 측면에서 위험합니다.
> 예: `niceeng-rental.co.kr`, `niceeng.co.kr`

### 실행

```bash
# 먼저 무엇이 바뀌는지만 확인
python3 tools/set_origin.py https://내도메인.co.kr --dry-run

# 실제로 이전 (917개 링크 + robots.txt + CNAME + 설정파일을 한 번에)
python3 tools/set_origin.py https://내도메인.co.kr
python3 tools/build_blog.py
python3 tools/apply_config.py
git add -A && git commit -m "사이트 주소 이전" && git push
```

그다음 스크립트가 출력하는 DNS 설정과 GitHub Pages 설정을 따라 하시면 됩니다.

> **구글 서치콘솔은 지금 주소 그대로 등록됩니다.** 구글은 URL 접두어 속성을 지원해서
> `https://pg5chb7mn6-blip.github.io/chungho-rental/` 로 바로 등록·색인 요청이 됩니다.
> 도메인을 기다리지 말고 아래 2-2번을 **오늘 먼저** 하십시오. 구글은 3~7일이면 색인이 붙습니다.

## 1. 사업자 정보와 인증코드 채우기 (10분)

```json

  "대표자명": "홍길동",
  "사업자등록번호": "000-00-00000",
  "통신판매업신고번호": "제0000-지역-0000호",
  "사업장 주소": "소비자 불만 처리가 가능한 실제 주소",
  "대표전화": "010-0000-0000",
  "사내 이메일": "상담 문의를 받을 이메일"

```

> **통신판매업 신고를 안 하셨다면** `통신판매업신고번호` 를 비워두고, 각 HTML 푸터에서 해당 줄 자체를 삭제하세요. 없는 번호를 적거나 "신고 예정"이라고 쓰면 허위 표시가 됩니다.

### 1-2. 반영

```bash
python3 tools/apply_config.py
```

남은 항목이 있으면 무엇이 비었는지 알려줍니다. 전부 채워질 때까지 반복하세요.

### 1-3. 커밋·배포

```bash

```

배포에 1~3분 걸립니다.

## 2. 검색엔진 등록 (30분) ❗가장 중요

### 2-1. 네이버 서치어드바이저

> **0번(주소 이전)을 끝낸 뒤에 하십시오.** 하위 경로 주소로는 등록 버튼 자체가 막힙니다.

1. https://searchadvisor.naver.com 접속 → 네이버 로그인
2. **웹마스터도구 → 사이트 관리 → 사이트 등록**
   `https://내도메인.co.kr/`  ← 반드시 호스트 루트. 뒤에 경로를 붙이면 거부됩니다
3. **소유확인 → HTML 태그** 선택 → 나오는 `content` 값을 복사
4. `ops/site.config.json` 의 `네이버_서치어드바이저_인증코드` 에 붙여넣기
5. `python3 tools/apply_config.py` → 커밋 → 푸시 → **1~3분 대기** → 서치어드바이저에서 "소유확인" 클릭
6. **요청 → 사이트맵 제출**: `sitemap.xml`
7. **요청 → RSS 제출**: `rss.xml`  ← 새 글을 네이버가 먼저 발견하게 하는 통로입니다. 빼먹지 마세요.
8. **요청 → 웹페이지 수집**: 아래 URL을 하나씩 넣어 수집 요청 (하루 할당량이 있으니 중요한 것부터)
   ```
   /chungho-rental/
   /chungho-rental/blog/
   /chungho-rental/jeongsugi-rental/
   /chungho-rental/blog/jeongsugi-rental-fee-breakdown/
   /chungho-rental/blog/rental-contract-checklist/
   /chungho-rental/office/
   ```
9. **검증 → 웹사이트 최적화 도구** 실행. 경고가 뜨면 그 항목만 손봅니다.

> 네이버는 등록 후 실제 검색 반영까지 **2주 안팎** 걸립니다. 안 뜬다고 중간에 설정을 계속 바꾸면 오히려 늦어집니다. 기다리세요.

### 2-2. 구글 서치콘솔 — **주소 이전과 무관하게 오늘 바로 하십시오**

1. https://search.google.com/search-console
2. **속성 추가 → URL 접두어** → `https://pg5chb7mn6-blip.github.io/chungho-rental/`
3. **소유확인 → HTML 태그** → `content` 값 복사 → `구글_서치콘솔_인증코드` 에 반영 → 커밋 → 확인
4. **Sitemaps** 에서 `sitemap.xml` 제출
5. **URL 검사** 에서 주요 페이지를 넣고 "색인 생성 요청"

구글은 보통 3~7일이면 색인이 붙습니다. 네이버보다 훨씬 빠릅니다.

### 2-3. 다음(카카오) — 5분

https://register.search.daum.net/index.daum 에서 사이트 등록. 검색량은 작지만 등록 비용이 5분입니다.

### 2-4. 빙 웹마스터도구 — 5분

https://www.bing.com/webmasters 에서 **구글 서치콘솔 데이터 가져오기**를 쓰면 5분이면 끝납니다.

## 3. 측정 도구 설치 (20분)

### 3-1. GA4

1. https://analytics.google.com 에서 속성 생성 → 웹 데이터 스트림 추가
2. 측정 ID(`G-XXXXXXXXXX`)를 `ops/site.config.json` 의 `ga4_measurement_id` 에 입력
3. `python3 tools/apply_config.py` → 커밋

### 3-2. 네이버 애널리틱스

1. https://analytics.naver.com 에서 사이트 등록
2. 발급된 ID를 `naver_analytics_id` 에 입력 → 같은 명령 실행

**네이버 유입은 GA4에서 잘 안 잡힙니다.** 네이버 애널리틱스를 따로 붙여야 네이버 검색·블로그에서 몇 명이 오는지 보입니다.

## 4. 네이버 블로그 쪽 설정 (20분)

- [ ] 블로그 **주제를 "비즈니스·경제"** 로 설정 (주제가 맞아야 해당 카테고리 검색에 잡힙니다)
- [ ] 블로그 이름·소개글에 **주력 키워드** 포함 ("청호나이스 정수기 렌탈 상담" 등)
- [ ] 프로필에 **공식 판매점**임을 명시 (본사 공식몰로 오인시키지 않기)
- [ ] 카테고리를 사이트 블로그와 같은 6개로 구성: 렌탈료·제품·계약·관리·사무실·지역
- [ ] 네이버 블로그 URL을 `ops/site.config.json` 의 `naver_blog_url` 에 기록
- [ ] **네이버 플레이스 등록** (지역 검색 유입. 오프라인 사업장이 있다면 필수) → `naver_place_url` 에 기록
- [ ] 블로그 위젯/프로필에 사이트 링크 1개 연결
